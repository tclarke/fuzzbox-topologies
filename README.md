# 60s Fuzz Pedal Topologies

This repo contains a number of circuit topologies common to 1960s guitar fuzz pedals.
These are not complete circuits but contain the important parts of the representative circuits.
None of the components are meant to have a model or type as you can freely play around
with those. Micro-Cap requires a model for certain components so I've entered some common
ones.

I used Micro-Cap 12.2.0.3 for the circuits. I think it's a great simulation tool with a pretty
intuitive interface. It was commercial software but when the company closed down, they released
the most recent version as abandonware. It is not FOSS and is only available for Windows but
it runs well in Wine. You can get the installer on [GitHub](https://github.com/NeelPatra/Micro-Cap-12-Archive)

The `.cir` files are Micro-Cap circuit files. I've included PNGs in case you don't have Micro-Cap.
